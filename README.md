Community Waste Reporting and Collection System (CWRCS)

Project Overview

The Community Waste Reporting and Collection System (CWRCS) is a proposed digital system designed to improve the way waste problems are reported and managed within communities in Freetown, Sierra Leone. The project was developed as part of a Programming Logic and Design assignment and demonstrates how computational thinking and basic programming logic can be applied to a real problem affecting the local community.

Waste management continues to be an important issue in Freetown. In some communities, rubbish can accumulate along roads, around markets, in gutters, drainage areas and other public spaces. When waste is not collected or disposed of properly, it can create unpleasant surroundings, attract pests, affect public health and contribute to blocked drainage systems.

Although waste collection services already exist, one challenge is communication between residents and the people responsible for collecting waste. Residents may notice a waste problem in their community before the responsible collection team becomes aware of it. This project therefore focuses on creating a simple and organized method through which residents can report these problems.

Proposed Solution

The proposed solution is the Community Waste Reporting and Collection System. The system would allow residents to submit information about waste problems they notice within their communities.

When making a report, a resident would provide their name, community, location of the waste problem, type of waste, a short description and the urgency level. The system would check that the necessary information has been entered before accepting the report.

After the information has been completed, the report would be classified as either Urgent or Normal depending on the urgency of the situation. For example, waste blocking an important drainage system could require more immediate attention than a small amount of rubbish waiting for normal collection.

The completed report would then be saved and given a unique report number before being sent to the appropriate waste collection team. The report would remain Pending while waiting for collection. After the waste has been successfully removed, the status would be changed to Resolved.

This creates a simple process:

Report Waste → Check Information → Determine Priority → Save Report → Send to Collection Team → Pending → Waste Collected → Resolved

Computational Thinking

The project uses computational thinking to break the waste reporting problem into smaller and more manageable parts.

Problem decomposition is used to separate the overall process into smaller tasks such as collecting resident information, recording the waste problem, checking information, determining priority, saving the report and updating its status.

Pattern recognition can help identify repeated waste problems. For example, several reports coming from the same community may show that the area experiences recurring waste collection difficulties.

Abstraction allows the system to focus only on information that is important for handling the report rather than collecting unnecessary information about residents.

Algorithm design is used to arrange all the activities in the correct order, beginning when a resident opens the reporting form and ending when the waste problem has been resolved.

Algorithm and Logical Design

A step-by-step algorithm was developed to show how the system should operate. The algorithm starts with opening the waste reporting form and entering information about the resident and waste problem.

The system then checks the information, determines the urgency of the report, saves it and provides a report number. The report is forwarded to the waste collection team and kept as Pending until collection takes place. After the waste has been removed, the report becomes Resolved.

Pseudocode and a flowchart are also included in the project to represent this process in a simple and understandable form.

Functions and Modular Design

The system is divided into smaller modules so that each part has a specific responsibility. These include the Resident Information Module, Waste Reporting Module, Information Checking Module, Priority Module, Report Management Module, Waste Collection Module and Status Update Module.

Different functions would perform tasks such as checking submitted information, determining the priority of a report, generating a report number, saving information and updating the status of a complaint.

Using modular design makes the system easier to understand because a large process is separated into smaller sections that work together.

Sustainable Development Goal

The project mainly supports Sustainable Development Goal 11: Sustainable Cities and Communities. This goal focuses on making cities and human settlements safer, more resilient and sustainable.

Improving the way waste problems are reported can contribute to cleaner communities and support better waste management. The project can also contribute to SDG 12: Responsible Consumption and Production, particularly through its connection to responsible waste management.

Open-Source Software

The proposed system could be developed as open-source software so that its design and source code can be made available for other people to study, improve and adapt.

This could be particularly useful in Sierra Leone because the system would not necessarily have to remain limited to Freetown. Other communities could adapt the basic idea according to their own waste-management needs.

Open-source development could also encourage students, programmers and other technology professionals to contribute ideas and improvements to the project.

Digital Public Goods

The CWRCS also has the potential to contribute to the idea of Digital Public Goods because it is designed to use technology to address a public and community problem.

Making the system openly available could allow other communities and organizations to adapt it rather than developing a completely new solution from the beginning.

The basic reporting structure could potentially be adapted in the future for other community problems, such as reporting blocked drainage systems, damaged public infrastructure or other environmental concerns.

Community Impact

The main beneficiaries of the project would be residents of Freetown because they would have a more organized method of reporting waste problems.

Waste collection teams could benefit from receiving clearer information about the location and nature of a problem. Local authorities could also benefit from having records showing where waste complaints occur and whether they have been resolved.

Other beneficiaries could include traders, businesses, schools, children, pedestrians and other people who use community spaces.

Community participation would be important to the success of the system. Residents would contribute by reporting problems accurately, while waste collection teams and local authorities would be responsible for responding to the reports and updating their status.

Long-Term Sustainability

For the system to remain useful over time, it would need regular management and maintenance. Reports would need to be monitored, and waste collection teams would need to update the system after completing their work.

The system should also remain simple and affordable so that it does not depend on expensive or complicated technology. Training could be provided to the people responsible for managing reports.

An open-source approach could further support sustainability by allowing developers to improve the system as technology and community needs change.

Most importantly, the long-term success of the project would depend on cooperation between residents, local authorities and waste collection teams. Technology can make communication easier, but the information provided through the system must still lead to real action within the community.

Conclusion

The Community Waste Reporting and Collection System demonstrates how basic programming logic can be applied to a real community problem. The project does not suggest that technology alone can solve all waste-management challenges in Freetown. Instead, it focuses on improving one important part of the process: communication between residents and waste collection services.

By allowing residents to report waste problems, organizing those reports according to priority and keeping track of whether they have been resolved, the proposed system could support a more organized approach to community waste management.

Overall, the project shows how computational thinking, algorithms, logical design, functions and modular design can be combined to create a simple digital solution that responds to a real need within Sierra Leonean communities.
